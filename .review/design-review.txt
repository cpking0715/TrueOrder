### D1 [P1] 新组件大量使用未定义样式类，偏离「舱单检索台」token
- 位置：`frontend/src/features/products/components/ContactsPanel.vue:85-137`、`ContactForm.vue:33-64`、`ContactItem.vue:39-72`、`WebsiteField.vue:72-141`、`EnrichBar.vue:81-126`；对照 `frontend/src/assets/main.css`（仅有 `.badge`/`.small`/`.muted` 等，无下列类）
- 问题：模板依赖 `.ghost`、`.error`、`.enrichbar`、`.contact-form`、`.contact-list`、`.contacts-panel`、`.website-field`、`.tags`、`.actions`、`.badge.warn`、`.badge.muted`，但 `main.css` 与各组件均无对应规则。结果是「取消/编辑/新增」与默认描边按钮同貌、错误文案无驳回红、联系人表单/列表无间距与分隔、EnrichBar 无色轨/分区。
- 建议：在 `main.css` 补齐：`button.ghost`（透明底+淡墨字，hover 描边 `--marine`）；`.error`/错误行复用 `.badge.excluded` 或 `--stamp` 左边轨；`.badge.warn`→`potential` 语义映射或改模板为 `badge potential`；来源/验证用 `badge`+`.muted` 文字而非 `.badge.muted`；`.contact-form`/`.enrichbar` 用 flex+gap（12px）与 `.filterbar` 对齐；`.contact-list` 去默认 list 样式并加虚线分隔（对齐 `.reason-list`）。

### D2 [P1] WebsiteField「确认是官网」失败时错误不可见
- 位置：`frontend/src/features/products/components/WebsiteField.vue:58-66`（`confirm` 写 `error`）、`75-110`（非编辑态模板无错误节点）、`139-142`（仅编辑态渲染 `.error`）
- 问题：非编辑态点「确认是官网」若 API 失败，`error` 有值但不渲染，用户无反馈；且 `.error` 本身无样式（见 D1）。
- 建议：在非编辑态 `</template>` 前增加 `<p v-if="error" class="badge excluded" role="alert">`；确认/保存期间 `:disabled` 并改文案为「确认中…」。

### D3 [P1] 抽屉信息层级把得分理由与提单证据压到补全区之后
- 位置：`frontend/src/features/products/components/CompanyDrawer.vue:125-151`（摘要→官网→联系人→ScoreSection→提单）
- 问题：产品核心差异点（得分理由可点回提单、`BillTable`）排在 `WebsiteField`+`ContactsPanel`（含查找/抓取/新增与可变长列表）之后，联系人稍多即需长滚才能看到证据；无折叠/锚点，与 brief「证据是否被挤压」风险一致。
- 建议：默认顺序改为摘要→`ScoreSection`→提单→官网→联系人；或得分/提单默认展开、联系人 `<details open>` 可收起；顶部加「得分理由 / 提单 / 联系人」页内锚点。

### D4 [P1] 买家表行可点但不可键盘操作
- 位置：`frontend/src/features/products/components/BuyerTable.vue:45-49`
- 问题：`tr.clickable` 仅 `@click`，无 `tabindex`/`keydown`，不在 `main.css` 的 `:focus-visible` 选择器覆盖的可聚焦控件内，键盘用户无法打开抽屉。
- 建议：行加 `tabindex="0"`、`role="button"`、`@keydown.enter.space.prevent` 触发同样的 `select`；CSS 为 `tr.clickable:focus-visible` 复用 `tr.highlighted` 的描边。

### D5 [P1] 交互四态不完整：全局无 disabled 态，联系人补全按钮无 loading
- 位置：`frontend/src/assets/main.css:138-151`（`button` 无 `:disabled`）；`ContactsPanel.vue:31-39,90-105`（`findContacts` 无 busy）；`EnrichBar.vue:98-123`（有 `:disabled="busy"` 但文案不变）；`ContactForm.vue`/`ContactItem.vue` 提交/删除无 pending
- 问题：`cursor: pointer` 在 disabled 时仍生效，禁用按钮看起来可点；查找/抓取可连点入队；EnrichBar busy 时仍显示「估计额度/确认执行」，loading 语义不清。
- 建议：`main.css` 增加 `:is(button,.btn):disabled { opacity:.55; cursor:not-allowed; }`；`ContactsPanel` 增加 `busy`，请求中禁用三按钮并切换文案；EnrichBar busy 时按钮文案改为「估计中…/执行中…」。

### D6 [P2] 行内 style 绕过设计系统间距/尺寸
- 位置：`EnrichBar.vue:94`；`JobsView.vue:57`；`ProductDetailView.vue:203`；`CompanyDrawer.vue:145`；`FilterBar.vue:26`；另有 `ImportPanel.vue`/`ProductsView.vue`/`ProductCard.vue` 同类写法
- 问题：宽度与 `margin-top` 写死在模板，与 token/工具类不一致，后续改版难统一。
- 建议：`main.css` 增加 `.input-narrow { width: 4.5rem }`、`.input-country { width: 7rem }`、`.stack-gap { margin-top: 12px }`、`.drawer h2 { margin-top: 16px }`，去掉行内 style。

### D7 [P2] 数据面未统一等宽：联系方式/提单码仍走正文比例字体
- 位置：`ContactItem.vue:35-38`（email/phone）；`WebsiteField.vue:77-82`（URL）；`BillTable.vue:30-49`（提单号/到港/税号未用 `.code`）；`ScoreSummary.vue:15-17`（最近到港用 `.num`）
- 问题：设计系统要求税号/提单号/日期等「码」用 `--mono`；新联系人区与抽屉提单表未遵守，和买家表 `td.code`/`td.num` 不一致。
- 建议：email/phone/URL/提单号/HS/到港日期加 `class="code"`；票数保留 `.num`；`ScoreSummary` 最近到港改为 `.code`。

### D8 [P2] EnrichBar 两段式状态切换视觉弱、主次不清
- 位置：`frontend/src/features/products/components/EnrichBar.vue:80-144`
- 问题：估计态与确认态仅靠 `v-if` 换节点，无步骤提示/左边轨；「确认执行」虽为 `primary`，但与额度文案、取消挤在同一行且 `.enrichbar` 无样式；`credits_needed===0` 时按钮禁用但无单独说明样式。
- 建议：容器用 `.notice` 或左边轨 `--hold` 标「待确认」；确认态标题行写「第 2 步·确认消耗额度」；0 家可执行时用 `.muted` 明示原因。

### D9 [P2] 抽屉联系人操作条拥挤、主次不分
- 位置：`ContactsPanel.vue:88-114`；`WebsiteField.vue:75-110`
- 问题：「查找联系方式 / 抓取官网 / 新增联系人」与标题挤在同一 `h3`；官网行又叠「确认是官网 / 编辑」。消耗额度的查找与免费抓取、本地新增视觉权重相同。
- 建议：标题与操作分行；查找用 `primary small`，抓取/新增用 `ghost small`；官网确认保留主按钮、编辑为 ghost。

### D10 [P2] 390px 断点未覆盖表格、筛选、补全条与抽屉宽表
- 位置：`frontend/src/assets/main.css:372-378`（仅 page/quickstart/hs/summary-grid）；买家/任务/提单均为 `table.grid` 无横向滚动包装
- 问题：720px 规则不够；390px 下多列表格必横向溢出或挤压；`.filterbar`/无样式的 `.enrichbar`/联系人表单未强制整宽堆叠；抽屉宽 `min(680px,94vw)` 尚可，但表头 uppercase 多列不可用。
- 建议：`@media (max-width:720px)` 增加 `.table-scroll { overflow-x:auto }` 包裹三处表格；`.filterbar`/`.enrichbar`/`.contact-form` 改为 column 且 `input,select,button{width:100%}`；抽屉内提单表同样加滚动容器。

### D11 [P2] CompanySummary 同名冲突用块级 `p.badge`，语义与徽章体系错位

### D12 [P2] JobsView 状态筛选用实心 primary，且标题行内样式
